# `sol/`: this engagement's material

Put everything you have about **this** customer project here: meeting notes, the use-case write-up, emails, requirement sheets, prior proposals, existing diagrams, pricing exports. Subfolders are fine.

- `sow-live start` reads this folder (md, txt, csv, json, docx, pdf) as pre-call context.
- The SoW pipeline reads it for background when it writes the SoW.
- Only this engagement's agents read it. Other customers' material goes in their own engagement folder (`sow-live new`).

Reference credentials by name; don't paste live secrets.
