# Reference: controlled vocabulary

Load this when choosing tags for a page. Use ONLY these canonical terms for `solution_tags`, `partner_tags`, and `aws_services`. If the right term isn't here, tell the user it's a candidate for the vocabulary rather than inventing a new canonical tag. This file mirrors the runtime vocabulary; the pinned **Controlled Vocabulary** page in the Handbook is the human reference.
